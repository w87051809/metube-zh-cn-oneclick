# AI 助手配置与隐私

AI 助手用于用中文解释失败原因、当前任务和自动修复顺序。它不是下载器的一部分，也不会代替固定下载规则。

## 可选配置

AI 助手和标题翻译共用下面三个服务器环境变量：

```text
TITLE_TRANSLATE_API_BASE
TITLE_TRANSLATE_API_KEY
TITLE_TRANSLATE_MODEL
```

接口需要兼容 OpenAI Chat Completions。没有配置时，网页会显示 `AI 尚未配置`，下载功能不受影响。

## 状态说明

| 状态 | 含义 |
| --- | --- |
| `AI 连接正常` | 接口可访问，认证通过 |
| `AI 密钥无效` | 服务返回 401 或 403 |
| `AI 请求太频繁` | 服务返回 429 |
| `AI 服务暂时异常` | 外部服务返回 5xx |
| `AI 服务连接超时` | 外部接口在规定时间内没有响应 |
| `AI 尚未配置` | 缺少接口地址或密钥 |

## 隐私设计

- API Key 只由服务器读取，状态接口不会把密钥返回浏览器。
- 浏览器只能看到供应商域名、模型名称和连接状态。
- AI 对话接口限制请求长度，并按客户端地址限制调用频率。
- AI 系统提示明确禁止输出服务器密钥、Cookie、令牌和内部地址。
- 发布仓库前会扫描常见 API Key、Cookie、私钥和内网地址。

## 安全要求

1. 不要把 API Key 写入 README、Issue、截图、Release Notes 或 Git 提交。
2. 不要把 `cookies.txt` 发给任何 AI 服务。
3. 如果密钥曾经出现在公开位置，应立即到供应商后台撤销并重新生成。
4. 服务器配置文件应只允许管理员读取。
5. 对外开放网页时，应额外配置反向代理认证或内网访问控制。
