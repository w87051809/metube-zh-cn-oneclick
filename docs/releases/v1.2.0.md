# v1.2.0：自动修复、AI 助手和界面升级

这是一次功能版本更新，重点解决 YouTube 临时 403、连接超时、格式兼容和失败记录难以判断的问题。

## 主要更新

### YouTube 自动修复

- 遇到可恢复错误时重新解析媒体地址，不继续使用已经过期的 CDN 链接。
- 依次尝试默认线路、`mweb`、匿名 `android_vr` 和兼容合并格式。
- 网络超时、临时 HTTP 错误和分片中断会自动重试。
- 默认下载并发从 3 调整为 2，降低批量订阅触发临时限制的概率。
- 默认每天凌晨 04:15 更新 yt-dlp nightly。

### 自动格式

- 不再强制 MP4，优先保证最佳可用画质和下载成功率。
- 自动模式优先非 AV1；必要时仍可以回退到 AV1。
- 最终文件可能是 WebM、MKV 或 MP4，取决于视频实际提供的格式。
- 最后兼容回退优先选择本身同时带视频和音频的流，减少合并失败。

### AI 助手

- 页面顶部增加 AI 助手入口。
- 可以解释失败原因、当前任务和自动处理顺序。
- API Key 只保存在服务器端，不会返回浏览器。
- AI 不参与格式和线路决策；AI 不可用时，下载器仍然按固定规则运行。

### 已完成列表和界面

- 同名任务显示“视频 / 字幕 / 封面”标签。
- 优化浅色、深色主题和下载控制台。
- 增加左侧快捷导航，订阅区提前并保留频道头像。
- 小封面保持原行高，支持悬停大图预览。
- 顶部保留清晰的 YouTube 登录入口和 Cookie 状态。

## 修复

- 修复 `HTTP Error 403` 和 CDN 连接超时后任务立即失败的问题。
- 修复部分视频 `Postprocessing: Conversion failed`。
- 修复最新版 MeTube 新增 `sponsorblock` 参数后，提交任务返回 HTTP 500 的兼容问题。
- 修复字幕成功与视频失败混在一起时难以判断的问题。

## 升级方法

重新运行安装脚本：

```bash
curl -fsSL https://raw.githubusercontent.com/w87051809/metube-zh-cn-oneclick/main/install.sh | sudo bash
```

升级不会主动删除下载目录和状态目录。完成后建议浏览器强制刷新一次。

## 回滚

升级前应保留 `/www/临时文件` 中的逐文件备份。

如需从 Git 标签重新安装上一版，应同时固定安装脚本和 `RAW_BASE`，避免旧脚本继续下载主分支的新文件：

```bash
curl -fsSL https://raw.githubusercontent.com/w87051809/metube-zh-cn-oneclick/v1.1.5/install.sh | \
  sudo env RAW_BASE='https://raw.githubusercontent.com/w87051809/metube-zh-cn-oneclick/v1.1.5' bash
```

回滚后重新检查容器状态和网页版本。
