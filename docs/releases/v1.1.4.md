# v1.1.4

## 本次发布

这是一次封面图文件大小显示修复版本。

## 修复

- 修复封面图任务在已完成列表里可能显示成同名视频大小的问题。
- 封面图任务现在只读取真实图片文件大小。
- 如果找不到真实图片文件，封面图大小会显示为空，不再拿视频大小冒充。
- 服务启动时会自动修正历史已完成封面图记录里的错误大小。
- 安装脚本缓存版本号更新到 `20260725-1`。

## 验证

- `node --check metube-zh-cn.js`
- Python AST 语法检查：`ytdl.py`、`subscriptions.py`、`dl_formats.py`
- `git diff --check`
- 敏感信息扫描
- 服务器 `bash -n install.sh`
- 服务器 MeTube 服务健康检查
- 已完成记录里的封面图大小修正为真实 JPG 大小
- GitHub Actions 质量门禁

## 升级说明

已安装用户刷新页面即可看到修正后的封面图大小。已有错误记录会在服务重启后自动修正。

## 回滚说明

如果要回滚，只需要恢复上一版 `ytdl.py`、`dl_formats.py` 和入口页脚本版本号。服务器下载目录和视频文件不受影响。
